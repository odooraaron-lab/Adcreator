# Venue Promo Studio

Enter a venue's name, address, website and socials. Claude reads them and writes ten 1920×1080 promo slides for in-venue screens, which you can edit and download as PNGs or a zip.

`index.html` is a single self-contained page built as a claude.ai artifact. The Claude features (research, slide writing, web reading, saving files) only work when it is opened as an artifact in claude.ai or the Claude desktop app. Opened elsewhere, the editor, slide rendering and example slides still work, but the buttons that ask Claude are disabled.
